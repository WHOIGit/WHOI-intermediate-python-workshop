# Intermediate Python: From Scripts to Reusable Projects

A two-session workshop (four 2-hour blocks) for scientists and technicians who
can write basic Python scripts and want to write code that others, including
their future selves, can find, run, and reuse. The lesson is built around real
[OOI](https://oceanobservatories.org/) CTD and DOSTA data from the Global
Irminger Sea Array (GI01SUMO) and a notebook-first workflow.

| Session | Block | Topic |
|---|---|---|
| 1 | 1 | Writing effective functions |
| 1 | 2 | Organizing functions into modules |
| 2 | 3 | Building a repository and managing environments with `uv` |
| 2 | 4 | Documentation and reuse |

The lesson website is built with [The Carpentries Workbench][workbench] and is
published at <https://reedan88.github.io/WHOI-intermediate-python-workshop/>.
